# Security Policy / 安全策略

## Supported versions
Only the latest release receives security fixes.

## Reporting a vulnerability
Please **do not** open a public issue. Use GitHub private vulnerability reporting
("Security" tab → "Report a vulnerability") on https://github.com/sean-y-wang/kongpilot-console/security/advisories/new (no email channel).

We aim to acknowledge within 3 business days and to provide a fix or mitigation plan within 30 days.

## 报告漏洞
请勿公开提 issue，使用本仓库 Security 页的 “Report a vulnerability” 私下报告。我们会在 3 个工作日内确认。

## Scope notes
KongPilot manages an existing Kong Admin API. Keep the Admin API off public networks and restrict it to the BFF; see docs/manuals/production-operations-guide.md.
