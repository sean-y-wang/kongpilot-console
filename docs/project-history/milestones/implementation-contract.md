# Shared implementation contract

All code belongs to /opt/kongpilot-console. Work only in assigned files. Root owns manifests, main.ts and app.module.ts.

Backend NestJS 12 (patched): global infrastructure providers DbService (infrastructure/db.service.ts), SecretService (infrastructure/secret.service.ts), RedisService (infrastructure/redis.service.ts), AuditService (modules/audit/audit.service.ts), KongService (infrastructure/kong/kong.service.ts). React Router 7 CSR APIs, ECharts 6.1 (security fixes). DevPortal will use a safe custom OpenAPI renderer instead of vulnerable swagger-ui-react transitive dependencies.

DbService APIs: query<T=any>(sql:string, params?:unknown[]):Promise<T[]>; one<T=any>(sql:string,params?:unknown[]):Promise<T|null>; exec(sql:string,params?:unknown[]):Promise<number>; transaction<T>(fn:(tx:DbService)=>Promise<T>):Promise<T>. PostgreSQL migrations automatically loaded in infrastructure/migrations/*.sql. Use parameterized SQL only.

KongService APIs: request<T=any>(clusterId:string, method:string, path:string, body?:unknown, query?:Record<string,string|number>):Promise<T>; probe(clusterId:string):Promise<any>; schema(clusterId:string,entity:string):Promise<any>; pluginSchema(clusterId:string,name:string):Promise<any>; list(clusterId:string,path:string,query?:Record<string,string|number>,cursor?:string):Promise<{items:any[],nextCursor:string|null,size:number}>. GET next URLs never followed. CRUD paths strictly version allowlisted; forbidden enterprise/newer paths never used. Calls require persisted registry cluster ID. Tag encoder implemented in infrastructure/kong/tags.ts: encodeTag(logical:string):string, decodeTag(physical:string):string, workspaceTag(code:string):string.

SecretService APIs: encrypt(value:unknown, context?:string):string; decrypt<T=any>(encrypted:string,context?:string):T; redact(value:unknown):any; fingerprint(value:unknown):string. AES-GCM encrypted values stored as text.

AuditService API: append(event:{actorId?:string|null,actorType?:string,clusterId?:string|null,workspaceId?:string|null,entityType:string,entityId?:string|null,action:string,before?:unknown,after?:unknown,result?:string,requestId?:string,ip?:string,workflowId?:string|null}):Promise<void>.

Global request guard populates req.user={id:string,username:string,superAdmin:boolean,permissions?:any[]} and req.requestId. @Public() decorator from common/auth.ts. Guard uses cookie or Bearer JWT. Mutations require X-CSRF-Token for cookie auth; bearer clients exempt. Envelope interceptor returns {data,meta:{requestId}} for JSON responses. Throw Nest HttpException with {code,message,fields?}. No success placeholders for missing provider data.

Controllers paths under /api/v1 (setGlobalPrefix): clusters, clusters/:clusterId/data-sources; all resource controllers clusters/:clusterId/... . Body JSON. Frontend fetch helper unwraps response.data, credentials include and CSRF attached. Avoid storing secrets in browser localStorage.

M0 cluster columns: id uuid, name text, environment text, admin_url text, labels text[], execution_mode text direct|approval, connection_secret text nullable, status text, version text nullable, capabilities jsonb, enabled_plugins text[], last_probed_at timestamptz, deleted_at timestamptz, created_at/updated_at timestamptz, revision int.
M0 data_sources columns: id uuid, cluster_id uuid, name text, type prometheus|loki, base_url text, auth_secret text nullable, enabled boolean, last_status text, last_probed_at timestamptz nullable, deleted_at timestamptz, created_at/updated_at timestamptz, revision int.

Test code uses Vitest, Playwright. No mock results represented as real Kong validation. M0 validates baseline; later milestones create additional migrations and tests.

## M1 contracts

AuthorizationService global (modules/authorization/authorization.service.ts) APIs assertCluster(user,clusterId,module,action), assertEntity(user,clusterId,entityType,action,entity), filterEntities(user,clusterId,entityType,items), scopeTags(user,clusterId,workspaceId,requestedTags), permissionVersion(user). M1 baseline superadmin-only; M4 implements full grants without callers changing. Do not use optional authz fallback that permits actors.

Entity API: GET/POST clusters/:clusterId/entities/:entityType, GET/PATCH/DELETE .../:entityId. GET clusters/:clusterId/schemas/:entityType. Lists {items,nextCursor,size,total:null} params size,cursor,tags,workspaceId,search,sort. Default native cursor; fuzzy search and sort use EntityIndexService with current Kong object and permissions revalidation, indexed:true and observed_at. Sort name:asc|desc or created_at:asc|desc. WorkspaceId BFF-only never forwarded Kong. Mutations header X-Idempotency-Key recommended, delete body {confirmed:true,confirm_name:name}. GET details {entity,relations,certificate?}, redact secrets unless explicit authorized reveal true. EntityService uses MutationService and delegates DELETE only to RecycleService.

Targets API GET/POST clusters/:clusterId/upstreams/:upstreamId/targets; GET .../health; PATCH .../targets/:targetId; DELETE .../targets/:targetId (recycle archive); POST .../targets/:targetId/healthy|unhealthy. Credentials GET/POST clusters/:clusterId/consumers/:consumerId/credentials/:kind (key-auth/basic-auth/jwt/oauth2/hmac-auth/acls), PATCH/DELETE .../:credentialId (recycle). Consumer credential permissions inherited explicitly from consumer by AuthorizationService future; no enabled field on nativecredentials.

MutationService (modules/mutations/mutation.service.ts) global API execute<T>(context:{clusterId:string,actor:AuthUser,entityType:string,entityId?:string,action:string,idempotencyKey?:string,requestId?:string,ip?:string,before?:unknown,payload?:unknown,workflowId?:string}, fn:()=>Promise<T>):Promise<T>. Persist idempotency state, requesthash, encrypted before state, after audit, uncertain status; serialize cluster mutation key while KongService innerwrite lock is distinct key. Approval mode rejected until workflow-ready M6/M11. Never direct HTTP raw Kong DELETE outside RecycleService.

RecycleService API archiveAndDelete(context same mutation plus entityType/entityId, confirmed:boolean):Promise<any>; list(clusterId,actor,...), preview(clusterId,id,actor), restore(clusterId,id,actor,confirmed), purge(clusterId,id,actor,confirmed). Capture complete affected graph using bounded Kong cursor traversal; if budget incomplete refuse deletion. Separate affected nodes from referenced shared parents. encrypted graph payload stablecontext recycle:<entryId>. OriginalIDs restore where supported; Target history restore new effectiveID. Basic-auth fail closed if rawpassword cannot recover, do not irreversibly delete unknown historicalsecret. CredentialStore in M1migration remembers encrypted created/rotated credentials for graphcapture. Recycle frontend includes all graph previews only redacted and typed confirmation. Expiry makes eligible for confirmed purge; no silent permanentdeletion.

GraphNode {key,type,id,path,data,affected,dependencies:string[],restoreData?,restorable,reason?}; GraphCapturerService.capture(cid,type,id,{parentId?,credentialKind?}) is read-only and bounds full traversal to100pages/10000records. Certificate inbound client_certificate reference rejects before deletion. Service.host matching an existing Upstream captures shared reference; ordinary DNS host is valid. No Kong cross-object transaction/CAS: external writers must use the same BFF mutation lock.

EntityIndexService globally owns search/upsert/remove/summary/refreshCluster, per-kind bounded background cursor cycles. 003_m1_index_cycles mark/sweep only completes successful cycles, preserves console-observed changes during cycle. GET clusters/:cid/inventory; POST inventory/refresh performs one page per kind. Raw secrets never stored in index.

GET clusters/:cid/mutations/:operationId returns authorized redacted durable receipt. Error envelope may include validated operationId/entryId/state for uncertain/partial failures; never blindly retry mutations. SecretService.redactError(errorValue,requestBody) additionally scrubs request secrets echoed in validator messages. All schema responses strip sensitive defaults while preserving field definitions; session plugin schema default secret is not public.

Applied SQL migrations 000–003 are immutable; add new migrations for subsequent milestones. API Docker process does not watch bind-mounted output: rebuild then explicit restart is required. Frontend build enforces dist0755/0644 for Nginx workers.
