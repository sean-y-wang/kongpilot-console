Kong 1.5.1 和 PostgreSQL 11 的维护状态受原需求版本约束。当前不自动升级网关，不将网络隔离当成漏洞修复。公网商业上线前需要受支持版本迁移或可验证的维护补丁，并重新验收。私人试用也必须控制网络入口、明确负责人、保存与演练备份，不能把本 RAM 验收环境当作持久生产。

Prometheus/Loki 已另外扫描更新候选，风险比原镜像减少，但尚有高危项目，仍不是已通过的发布版本。固定 decK 1.2.4 用于 Kong 1.5 兼容验收，运行在隔离的短期工具环境；其旧 Go/依赖风险独立保留。

LDAP/OIDC、邮件/Slack/飞书真实服务和外部备份存储未配置，结果记录为 `not-tested`。M9–M11 为 `deferred`。已完成的本地协议、源码和历史真实业务证据不能代替这些外部验证。
