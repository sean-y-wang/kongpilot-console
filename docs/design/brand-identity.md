# KongPilot 品牌与视觉规范

英文产品名称：**KongPilot**。中文产品名称：**Kong 网关管理平台**。仓库名称：`kongpilot-console`。npm 工作区命名空间：`@kongpilot/*`；新构建镜像命名空间：`kongpilot/*`。

## 品牌应用

控制台、登录页、浏览器标题、favicon、开发者门户、Swagger、通知标题和导出审阅提示统一使用 KongPilot。中文全称用于登录页、副标题、文档与产品介绍；导航区域保留英文产品名便于识别。门户的租户自定义名称仍由租户配置。

## 当前视觉方案

以用户提供的企业后台参考图和最新具体规范为依据：极浅灰白基底、纯白实体侧栏、轻磨砂卡片，三级中性灰文字和低饱和靛蓝操作色。保持留白、细描边、8px 圆角与柔和阴影。支持浅色、深色；实际页面见 视觉预览，具体变量见 [CSS 清单](css-variables.md)。首次 [蓝白效果图](kongpilot-overview-proposal.png) 是已经被后续要求替代的历史提案。

| 项目 | 浅色 | 深色 |
| --- | --- | --- |
| 画布 | `#F7F8FA` | `#121820` |
| 侧栏 | `#FFFFFF`，无模糊 | `#1B2430`，无模糊 |

不增加夸张光效、背景渐变或多余装饰，也不宣称复刻官方 macOS 规范。正常、警告、错误保留语义色、文字和图标；浏览器不支持 backdrop-filter 时降级为清晰的实色面板。支持键盘焦点、触屏操作及减少动态/透明效果偏好。截图使用示例 BFF 数据，不代表生产数据或真实网关验收。

## 更名兼容边界

更名不修改 Kong 的源码、镜像实现或 1.5 API 白名单，也不更改业务实体或租户自定义品牌。

SQL000–011、已有数据库 `kongos` / `kongos_app`、Cookie 名称、JWT issuer/audience、`KongOS-Deck` 授权协议、`x-kongos-event-id`、加密 AAD、Redis 键和 `KONGOS_*` 部署参数属于既有技术契约。它们继续保留，以免破坏会话、凭证、审计链或历史恢复能力；在手册中明确说明，不将存储协议迁移伪装成文本更名。

已有 Compose 项目升级必须沿用原 project name 与卷；新部署使用 `kongpilot-production`。固定镜像摘要和既有恢复包保持原样。

## 玻璃材质与 Logo 更新

白色卡片使用极轻半透明磨砂，辅以低浓度阴影；按钮保留微弱内高光，背景和侧栏不做玻璃。[蓝灰玻璃 K 标识](kongpilot-logo-glass.png) 使用透明 PNG，应用于控制台、登录页、门户与 favicon。标识沿用已认可的 K 轮廓与玻璃层次，按最新反馈降低蓝色饱和度，采用与 `#59668D` 操作色协调的蓝灰/靛蓝材质；简化 SVG 作为备用图形保留。

## 最终色彩与明暗模式

色彩以本页最新表格和 CSS 清单为准。控制台、登录、门户、表格、弹窗与 Vitals 图表继续支持同步切换；初次跟随系统，选择保存在 `kongpilot.appearance`，不修改认证、范围或恢复存储。浅色采用白色容器、三级灰度和靛蓝点缀；深色是相应的可读性适配。

## 侧边导航

固定品牌区与底栏，菜单独立滚动，使用动态视口高度适应桌面与移动端。分组可折叠，显示当前授权菜单数量；进入页面时自动展开并定位选中项。底栏提供上下滚动按钮，滚动范围结束时禁用。桌面单项高度 36px，移动端 40px；不通过缩小文字强行挤入全部功能。折叠和主题选择不修改权限、集群或工作区。
