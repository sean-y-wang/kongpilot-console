# Support

- **Questions & ideas:** open a [GitHub issue](https://github.com/sean-y-wang/kongpilot-console/issues/new/choose).
- **Bugs:** use the bug report template; redact secrets, hostnames and IPs.
- **Security vulnerabilities:** do **not** open an issue — see [SECURITY.md](SECURITY.md).
- **Docs:** start at the [documentation index](docs/README.md).

KongPilot is a community project with no commercial support SLA.
